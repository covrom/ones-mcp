# ones-mcp — MCP-сервер для 1С:Предприятие 8.3

> Агент спрашивает. База отвечает.

**ones-mcp** — служба Windows, которая подключает AI-ассистентов и MCP-клиентов (Claude, Cursor, Cherry Studio и другие) к информационным базам 1С:Предприятие 8.3.

Работает на **любой базе** без доработки конфигурации и без установки расширений. Запросы — **только на чтение** (ВЫБРАТЬ).

- 1С:Предприятие 8.3 · Streamable HTTP · только чтение (ВЫБРАТЬ)
- Служба Windows с автозапуском и перезапуском при сбое
- База не меняется: не затрагивается ни один объект конфигурации

## Как это работает

Агент задаёт вопрос — ones-mcp выполняет запрос в базе 1С:Предприятие 8.3 и возвращает результат агенту.

```
MCP-клиенты (агенты)              ones-mcp (служба Windows)         1С:Предприятие 8.3
Claude · Cursor · Cherry Studio   MCP :3298                         1cv8.exe · внешняя обработка .epf
        │                               │                                  │
        ├── MCP · Streamable HTTP ──────►│── 1cv8.exe ENTERPRISE /Execute ──►│
        │                               │    ВЫБРАТЬ · только чтение         │
        │◄────────── rows · rowCount ───┤◄─ POST результата (loopback) ──────┤
        │            durationMs         │    HTTP-приёмник 127.0.0.1:3297    │
                                        │                                  │
                                        │            Информационная база:   │
                                        │   ERP · Бухгалтерия · УТ · ЗУП    │
```

Встроенная в пакет внешняя обработка копируется во временный файл, текст запроса — в отдельный файл, и клиент 1С:Предприятие 8.3 запускается в режиме предприятия. Обработка выполняет запрос и возвращает результат локальному приёмнику службы. Всё происходит на машине, где установлена 1С:Предприятие 8.3; пароль 1С в логи не записывается.

## Три инструмента

Сервер публикует по протоколу MCP ровно три инструмента.

### `list_bases`

Информационные базы, найденные на компьютере: id, имя, строка соединения, версия платформы.

### `list_platforms`

Установленные платформы 1С:Предприятие 8.3: имя, версия, путь к исполняемому файлу `1cv8.exe`.

### `run_query`

Выполняет запрос на языке запросов 1С:Предприятие 8.3 (ВЫБРАТЬ) и возвращает строки результата в JSON — базу он не записывает и не изменяет.

**Параметры:**

| Параметр | Описание |
| --- | --- |
| `query` | Текст запроса на языке запросов 1С:Предприятие 8.3 (обязателен). Пример: `ВЫБРАТЬ 10 КАК Кол_Позиций ИЗ Справочник.Номенклатура` |
| `base` | id или имя базы из `list_bases`. Если ни база, ни строка соединения не заданы — сервер вернёт вопрос о выборе базы и список доступных баз; клиент уточнит у пользователя и повторит запрос |
| `limit` | Сколько строк вернуть. По умолчанию — 1000; при обрезке в ответе будет `truncated=true` |

В ответе: `rows`, `rowCount`, `truncated`, `durationMs`.

## Подключение — три шага

Вся настройка происходит вокруг строки соединения и учётной записи 1С:Предприятие 8.3 — в базе ничего не меняется. Если чего-то не хватает, сервер сам объяснит, что именно и где задать.

### 1. Установите службу

Запустите `setupOnesMCP.exe` от имени администратора и задайте параметры на странице конфигурации. Инсталлятор создаст службу «MCP-сервер для 1С:Предприятие» с автозапуском и перезапуском при сбое. Права администратора нужны только на этом шаге.

Удаление — `uninstall.exe` в каталоге установки.

### 2. Добавьте сервер в MCP-клиент

Один блок конфигурации — и инструменты появятся у агента:

```json
// mcp.json — Claude Desktop, Cursor, Cherry Studio и другие
{
  "mcpServers": {
    "1c": {
      "url": "http://127.0.0.1:3298/mcp",
      "headers": {
        "X-Mcp1c-Connection": "Srvr=\"сервер\";Ref=\"база\";",
        "X-Mcp1c-User": "mcp-robot",
        "X-Mcp1c-Password": "••••••"
      }
    }
  }
}
```

### 3. Скажите, от чьего имени работать

Задайте строку соединения, пользователя и пароль 1С:Предприятие 8.3 заголовками `X-Mcp1c-*`. Платформу и таймаут можно не указывать: по умолчанию — самая свежая платформа и 300 секунд.

При ошибочных учётных данных сервер не молчит: в ответе — подробная подсказка, где задать пользователя, что он должен существовать в ИБ и как проверить вход через обычный клиент 1С:Предприятие 8.3.

## Что нужно для работы

- 1С:Предприятие 8.3 — платформа установлена на сервере, где запущена служба ones-mcp.
- Доступная информационная база — файл или серверная база, до которой есть строка соединения.
- Пользователь 1С:Предприятие 8.3 с правами чтения на нужные объекты и правом запускать внешнюю обработку.

**Одно условие в клиенте 1С:Предприятие 8.3**

У пользователя должно быть снято ограничение «Защита от опасных действий» — иначе внешняя обработка, через которую выполняется запрос, не запустится. Это настройка пользователя, а не базы.

## Частые вопросы

**Почему «без доработки и без расширений»?**

Типовые коннекторы к 1С:Предприятие 8.3 требуют поставить расширение или дополнение конфигурации, добавить реквизиты и регистры либо развернуть на базе сторонние компоненты. ones-mcp работает как любой клиент 1С:Предприятие 8.3: указывает базу по строке соединения, подставляет пользователя и выполняет запрос на языке запросов. Поэтому конфигурацию базы не трогают — ни в одном объекте — и одинаково работает на ERP, Бухгалтерии, УТ, ЗУП, КА и любой другой базе 8.3.

**Сервер может что-то изменить в моей базе?**

Нет. `run_query` выполняет только запросы на чтение (ВЫБРАТЬ): сервер не записывает и не изменяет данные. Пользователь 1С:Предприятие 8.3 при этом должен иметь лишь права чтения на объекты, к которым обращается запрос.

**Какие агенты поддерживаются?**

Любой MCP-клиент: Claude Desktop, Cursor, Cherry Studio, VS Code, Windsurf и собственные агенты. Подключение — по Streamable HTTP к службе. Привязки к одному вендору нет.

**Какие ограничения у ones-mcp?**

Только 1С:Предприятие 8.3. Запрос выполняется только на сервере или компьютере, где установлена 1С:Предприятие 8.3 и служба ones-mcp. По умолчанию служба слушает localhost — публикуя адрес наружу, помните: любой подключившийся клиент выполняет произвольные (только на чтение) запросы от имени заданного пользователя 1С:Предприятие 8.3.
